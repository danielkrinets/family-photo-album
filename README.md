# Семейный фотоальбом

Статический сайт: главный экран со стеклянным доком-переключателем городов и
вращаемой 3D-сферой с фото прямо под заголовком (тап по ней разворачивает на
весь экран, там же можно вращать и открывать фото).

## Как добавить фото в существующий город

Просто залить файл(ы) через GitHub (**Add file → Upload files**) в папку
`photos/<город>/` с именем `photoN.jpg`, где N — следующий свободный номер
(`photo1.jpg`, `photo2.jpg`, `photo3.jpg`, ...). Сайт сам их находит при
загрузке страницы — ничего в коде трогать не нужно. Максимум ищется до
`photo30.jpg`, дырки в нумерации не страшны.

## Как добавить новый город

1. Создать папку `photos/<город>/` и положить туда `cover.jpg` (фон/обложка)
   и `photo1.jpg`, `photo2.jpg`, ... (см. выше).
2. Добавить объект в `data/albums.js`, по образцу уже существующих.

Больше ничего трогать не нужно — сборки нет, это чистый HTML/CSS/JS.

## Локальный запуск

```bash
python3 -m http.server 8934
```

и открыть http://localhost:8934 (открывать напрямую как файл нельзя — сфера
грузит текстуры через fetch, это требует http-сервер).

## Деплой

GitHub Pages, ветка `main`, папка `/ (root)`.
