# Семейный фотоальбом

Статический сайт: главный экран со стеклянным доком-переключателем городов,
внутри каждого города — вращаемая 3D-сфера с фото (тап по центральному фото
открывает его на весь экран с кнопкой "Скачать").

## Как добавить новый город/фото

1. Создать папку `photos/<город>/thumb/` (превью ~512×512, для сферы) и
   `photos/<город>/full/` (оригиналы, для полноэкранного просмотра и скачивания).
2. Добавить объект в `data/albums.js`, по образцу уже существующих.

Больше ничего трогать не нужно — сборки нет, это чистый HTML/CSS/JS.

## Локальный запуск

```bash
python3 -m http.server 8934
```

и открыть http://localhost:8934 (открывать напрямую как файл нельзя — сфера
грузит текстуры через fetch, это требует http-сервер).

## Деплой

GitHub Pages, ветка `main`, папка `/ (root)`.
